# Blueprint Memory Lab

一个面向 UE5 初学者的 Blueprint 中英学习网页，结合间隔复习、拆词记忆、场景串联与官方资料查询。

## 功能

- 573 个 UE5 Blueprint 常用词条，支持中英文搜索
- 新词认义、主动回忆与艾宾浩斯式间隔复习
- 今日词单，以及独立的已学词与到期复习页面
- 444 个多词组节点拆词记忆
- 单词释义查询与有道词典跳转
- 有道词典英文朗读，并在不可用时切换到系统语音
- 每个词条的联想画面、记忆方法和自测问题
- 可编辑并本地保存的个人联想笔记
- 8 条 Blueprint 场景逻辑链
- 16 条 Epic 官方中文文档与学习资源
- 教程支持学习路径、分类、难度、资料类型、目的与知识标签筛选
- 本地学习进度、JSON 导入导出、深色模式与移动端布局

## 使用

无需安装依赖或启动服务器，直接打开 `index.html`。

建议使用最新版 Microsoft Edge 或 Google Chrome。

学习记录保存在浏览器 `localStorage` 中。语音朗读使用浏览器系统语音或有道词典在线音频。
